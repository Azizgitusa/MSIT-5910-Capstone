Portfolio: Nonprofit Food Assistance Database
Project Title : Database System for Nonprofit Food Assistance


My Role: Solo developer (full project lifecycle from problem analysis to deployment)
Project Duration
4 months (Capstone project, MSIT 5910)
Technologies Used
•	Python (Tkinter for desktop GUI)
•	MySQL (database)
•	Git & GitHub (version control)

Problem Solved
Small food banks cannot afford expensive database software. They rely on paper records and spreadsheets, causing slow service, lost information, and difficult reporting.
What I Built



A simple, free, desktop database system that runs on a local Windows computer. It helps staff and volunteers:
•	Manage people served (add, edit, delete, search)
•	Track donors and donations
•	Store food distribution locations
•	Schedule appointments with dropdown lists (no need to remember IDs)
•	Generate reports (daily, weekly, monthly, yearly, donor list, appointment list, IRS summary)
•	Control user access (admin, editor, viewer roles with table level permissions)


Key Results
•	Module load time: 0.5 seconds
•	Report generation time: 0.4 seconds
•	New user can complete core tasks within 6 minutes without a manual

What Makes This Project Special
•	Zero budget – all free, open source tools
•	On premise – data stays on the nonprofit’s own computer
•	User friendly – dropdowns instead of typing IDs
•	Role based security – protects sensitive information
